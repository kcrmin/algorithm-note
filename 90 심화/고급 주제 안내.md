# 고급 주제 안내

> **지금 외울 템플릿은 없다.** 아래 조건이 실제 문제에 나타났을 때 하나씩 추가한다.

## 당장 암기 목록에서 뺀 주제

| 주제 | 필요한 조건 | 먼저 익힐 내용 |
|---|---|---|
| 세그먼트 트리 / Fenwick 트리 | 값 갱신과 구간 질문이 반복되어 누적합을 매번 다시 만들 수 없음 | 누적합, 인덱스 |
| Trie | 많은 문자열의 접두사 탐색을 반복 | 문자열, 해시 |
| KMP | 긴 문자열에서 패턴 매칭을 효율적으로 반복 | 문자열, 접두사와 접미사 |
| SCC | 방향 그래프에서 서로 도달 가능한 정점 그룹 | DFS, 역방향 그래프 |
| 벨만–포드 | 시작점 최단거리에 음수 간선이 있음, 음수 사이클 판별 | 거리 갱신, 다익스트라와 차이 |
| 직접 구현 연결 리스트 | 노드 참조를 알고 중간 삽입·삭제를 반복 | 참조, 배열·Map으로 위치 찾기 |
| 버킷 | 점수·등급 범위가 작아 그룹별로 관리 가능 | 빈도 배열, 해시 |
| 게임 DP / 미니맥스 | 차례가 바뀌며 상대의 최선까지 고려 | 재귀, DP 상태 |
| 메모이제이션 | 재귀에서 같은 상태를 반복 계산 | DP; 캐시 키에 미래를 결정하는 상태 전부 포함 |
| 가지치기 | 버릴 분기가 정답을 개선할 수 없다는 근거가 있음 | 백트래킹; 남은 비용이 음수이면 현재 비용만으로 자르면 안 됨 |

기존 B형 최적화의 비율·packed long·배열 풀·timestamp 같은 변형은 핵심 암기 목록에서 뺐다. 특정 비율을 모든 기업 시험의 출제 빈도처럼 사용하지 않는다. 핵심 구현이 맞고 실제 제한에서 병목이 확인될 때 최적화한다.

기존 상세 자료 전체는 볼트 밖 원본 백업에 보존했다. 다시 필요해지면 그 주제 하나만 이 볼트 형식으로 정리해 추가한다. 원본 전체를 가져와 학습 목록을 다시 늘리지 않는다.

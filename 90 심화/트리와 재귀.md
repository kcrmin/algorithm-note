# 트리와 재귀

> **암기 한 줄:** 트리는 연결되고 사이클이 없는 그래프. 루트를 정하고 부모를 기록하면 위·아래가 생긴다.

## 언제 쓰나

조직도·부모 자식·트리의 부분 구조를 탐색할 때 쓴다. 먼저 [[DFS와 그래프]]와 [[BFS]]를 익힌다. 아래 코드는 정점 0~n-1의 **연결된 무방향 트리**를 입력받아 부모 배열을 만든다. n ≥ 1, 유효한 root, 간선 n-1개가 전제다. 시간·공간 `O(n)`.

## 외울 템플릿

```java
import java.util.*;

class TreeTemplate {
    static int[] parents(int n, int[][] edges, int root) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }
        int[] parent = new int[n];
        Arrays.fill(parent, -1);
        Queue<Integer> queue = new ArrayDeque<>();
        parent[root] = root;
        queue.offer(root);
        while (!queue.isEmpty()) {
            int current = queue.poll();
            for (int next : graph.get(current)) {
                if (parent[next] != -1) continue;
                parent[next] = current;
                queue.offer(next);
            }
        }
        return parent;
    }
}
```

## 왜 이렇게 쓰나

간선 `0-1, 0-2, 2-3`, 루트 0이면 처음은 `[0,-1,-1,-1]`이다. 0을 꺼내면 1과 2의 부모가 0이 되어 `[0,0,0,-1]`. 2를 꺼내면 3의 부모가 2가 되어 `[0,0,0,2]`다.

무방향 간선은 양쪽에 저장되어 2에서 0도 다시 보인다. 하지만 `parent[0]`은 이미 0이므로 건너뛴다. 루트를 -1로 남겨 두면 자식이 루트를 다시 발견할 수 있어 처음부터 자신을 부모로 기록한다. 이 값은 실제 부모가 있다는 뜻이 아니라 **방문 표시용 약속**이다.

## 바꿀 부분과 실수

- 사이클이 있거나 끊겨 있으면 입력은 트리가 아니다. 위 코드를 트리 검증 함수로 쓰지 않는다.
- 부분 트리 크기처럼 자식의 결과를 모으는 문제는 자식 처리 후 부모 값을 갱신한다. 단순 방문 순서와 목적이 다르다.
- 일자형 트리의 재귀 깊이는 n이다. 깊으면 재귀 대신 큐·스택을 검토한다.

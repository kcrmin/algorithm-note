# 수학 도구

> **암기 한 줄:** 최대공약수는 나머지 반복. 최소공배수는 먼저 나누고 곱한다. 나머지는 매 단계 줄인다.

## 언제 쓰나

약수·배수·주기 또는 큰 경우의 수의 나머지가 필요한 문제에서 연다. 아래 gcd/lcm은 **음수가 아닌 값**을 입력받는다. 두 수 모두 0이면 gcd=0으로 약속한다.

## 외울 템플릿

```java
class MathTemplate {
    static long gcd(long a, long b) {
        while (b != 0) {
            long remainder = a % b;
            a = b;
            b = remainder;
        }
        return a;
    }

    static long lcm(long a, long b) {
        if (a == 0 || b == 0) return 0;
        return Math.multiplyExact(a / gcd(a, b), b);
    }

    // a >= 0, exponent >= 0, 1 <= mod <= Integer.MAX_VALUE
    static long modPow(long a, long exponent, long mod) {
        long result = 1 % mod;
        a %= mod;
        while (exponent > 0) {
            if ((exponent & 1) == 1) result = result * a % mod;
            a = a * a % mod;
            exponent /= 2;
        }
        return result;
    }
}
```

## 왜 이렇게 쓰나

`gcd(12,8)`은 `(12,8) → (8,4) → (4,0)`이 되어 4다. 12와 8을 모두 나누는 수는 `12-8=4`도 나눈다. 같은 원리로 나머지를 계속 남기면 공약수를 유지하면서 수가 줄어든다. 시간은 두 양수가 주어졌을 때 `O(log min(a,b))`다.

최소공배수는 `12 / 4 * 8 = 24`. `a*b/gcd`보다 중간값이 작아진다. 하지만 **먼저 나누어도 최종 결과가 long을 넘으면 저장할 수 없다.** `multiplyExact`는 그런 경우 예외를 낸다.

거듭제곱 `3^5`는 `3 × (3²)²`다. `3^5 % 7`을 실행하면 다음과 같다.

| 반복 시작 `(result, a, exponent)` | 홀수이면 result 갱신 | a를 제곱·지수를 절반으로 줄인 뒤 |
|---|---|---|
| `(1,3,5)` | `1×3 % 7 = 3` | `(3,2,2)` |
| `(3,2,2)` | 짝수라 그대로 3 | `(3,4,1)` |
| `(3,4,1)` | `3×4 % 7 = 5` | `(5,2,0)` → 종료 |

지수가 홀수일 때는 a 한 개를 result로 빼 놓는다. 나머지는 짝수 개이므로 a를 제곱하고 지수를 반으로 줄여 같은 값을 표현한다. 지수를 절반씩 줄이므로 `O(log exponent)`. 나머지로 줄인 두 값의 곱도 `mod²`에 가깝다. 위 코드가 mod를 int 최댓값 이하로 제한하는 이유는 그 곱이 long 안에 들어가도록 하기 위해서다. 임의의 long 크기 mod에 그대로 쓰지 않는다.

## 바꿀 부분과 실수

- Java의 음수 `%`는 음수일 수 있다. 양수 mod에서 값 하나를 정규화할 때는 `Math.floorMod(value, mod)`를 쓴다.
- 나머지 상태에서 일반 나눗셈은 성립하지 않는다. 역원은 별도 조건이 필요한 후속 주제다.
- 음수를 포함한 gcd 확장은 Long.MIN_VALUE의 절댓값 문제까지 생각해야 하므로 이 템플릿의 범위에서 제외한다.

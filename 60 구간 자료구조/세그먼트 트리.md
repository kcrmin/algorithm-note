# 세그먼트 트리

> **핵심:** 각 노드는 자신의 구간 합을 저장한다. 한 원소를 바꾸면 그 원소에서 루트까지의 조상만 다시 계산한다.

## 개념

세그먼트 트리는 배열 구간을 두 부분씩 나누고, 각 부분을 합친 결과를 부모에 저장한다. 질의 구간을 겹치지 않는 `O(log N)`개 노드로 덮어 답하고, 한 원소의 변경도 `O(log N)`개 조상에만 영향을 준다. 아래는 **한 원소 대입 + 구간 합**을 처리하는 반복형 구현이다.

## 적용 조건

| 연산 | 시간 |
|---|---|
| 생성 | `O(N)` |
| `set(index, value)` | `O(log N)` |
| `sum(left, right)` | `O(log N)` |
| 공간 | `O(N)` |

- 외부 API는 **0-index, 양 끝 포함**이다. `left > right`인 빈 구간의 합은 `0`이다.
- 합·최솟값·최댓값처럼 구간 결과 두 개를 결합할 수 있을 때 사용한다. 아래 코드는 합 전용이며 빈 구간의 항등원은 `0`이다.
- 값이 바뀌지 않는 합은 [[누적합]], 한 원소에 더하기와 합만 필요하면 [[Fenwick 트리]], 구간 전체를 바꾸면 [[Lazy Propagation]]을 함께 비교한다.

## Java 템플릿

```java
final class SegmentTree {
    private final int n;
    private final int size;
    private final long[] tree;

    SegmentTree(long[] a) {
        n = a.length;
        int s = 1;
        while (s < n) s <<= 1;
        size = s;
        tree = new long[size << 1];
        for (int i = 0; i < n; i++) tree[size + i] = a[i];
        for (int i = size - 1; i > 0; i--) {
            tree[i] = tree[i << 1] + tree[i << 1 | 1];
        }
    }

    void set(int index, long value) {
        if (index < 0 || index >= n) throw new IndexOutOfBoundsException();
        int node = size + index;
        tree[node] = value;
        while ((node >>= 1) > 0) {
            tree[node] = tree[node << 1] + tree[node << 1 | 1];
        }
    }

    long sum(int left, int right) {
        if (left > right) return 0;
        if (left < 0 || right >= n) throw new IndexOutOfBoundsException();
        int l = left + size;
        int r = right + size;
        long result = 0;
        while (l <= r) {
            if ((l & 1) == 1) result += tree[l++];
            if ((r & 1) == 0) result += tree[r--];
            l >>= 1;
            r >>= 1;
        }
        return result;
    }
}
```

> [!info]- 원리와 코드 설명
>
> `a = [2, 1, 3, 4, 5]`이면 `size = 8`이다. 리프 `tree[8..15]`에 `[2, 1, 3, 4, 5, 0, 0, 0]`을 넣는다. 남는 리프가 `0`이면 합에 영향을 주지 않고, 리프 시작점을 2의 거듭제곱으로 맞추면 같은 깊이의 노드가 같은 길이의 구간을 맡는다.
>
> 부모는 `node / 2`, 왼쪽 자식은 `node * 2`, 오른쪽 자식은 `node * 2 + 1`이다. 따라서 `tree[4] = 2 + 1 = 3`, `tree[5] = 3 + 4 = 7`, `tree[2] = 3 + 7 = 10`이다. 큰 번호부터 만들면 자식 값이 이미 준비되어 있다.
>
> `sum(1, 3)`은 다음처럼 처리된다.
>
> | 단계 | `l`, `r` | 선택하는 노드 | 누적 합 |
> |---|---|---|---:|
> | 리프 | `9, 11` | `l`이 홀수이므로 `tree[9] = 1` | 1 |
> | 부모로 이동 | `5, 5` | `l`이 홀수이므로 `tree[5] = 7` | 8 |
> | 다음 이동 | `3, 2` | `l > r`이므로 종료 | 8 |
>
> - **왼쪽 끝이 홀수면 먼저 꺼낸다.** 홀수 노드는 오른쪽 자식이다. 그대로 부모로 올라가면 범위 밖인 왼쪽 형제까지 포함하므로, 현재 노드만 더한 뒤 `l++`한다.
> - **오른쪽 끝이 짝수면 먼저 꺼낸다.** 짝수 노드는 왼쪽 자식이다. 부모로 올라가면 범위 밖인 오른쪽 형제가 섞이므로, 현재 노드만 더한 뒤 `r--`한다.
> - **나머지만 부모로 올린다.** 끝의 단독 노드를 제거하면 남은 노드는 형제 쌍으로 묶인다. 양 끝을 `>> 1`하면 이미 선택한 구간과 겹치지 않는 더 큰 구간을 검사한다.
> - **대입 후 조상을 재계산한다.** `set(2, 9)`는 `tree[10] = 9`로 바꾸고 `5 → 2 → 1`을 고친다. `tree[5] = 13`이 되므로 같은 `sum(1, 3)`은 `1 + 13 = 14`가 된다.
>
> ### 주의점
>
> - `set`은 기존 값에 더하지 않고 새 값으로 대입한다.
> - 최솟값으로 바꾸려면 결합 연산뿐 아니라 빈 리프·결과 초기값도 양의 무한대로 바꿔야 한다.
> - 문자열 이어 붙이기처럼 결합 순서가 중요한 연산은 왼쪽·오른쪽 결과를 따로 모아 순서대로 합쳐야 한다. 이 템플릿은 교환법칙이 성립하는 합 전용이다.
> - 빈 배열은 생성할 수 있으며 `sum(0, -1)`은 `0`이다. 실제 원소를 조회하거나 대입할 수는 없다.

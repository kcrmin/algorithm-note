# 다익스트라

음수 없는 가중치 그래프에서 가장 가까운 후보부터 최단거리를 구한다.

> **기억:** 최소 거리 꺼냄 → 오래된 후보 버림 → 목적지면 종료 → 이웃 거리 개선 → 힙에 넣기.

**전제:** 모든 가중치 0 이상, 유향 그래프. 시간 `O(V+E log(E+2))`, 공간 `O(V+E)`, 거리 long.

## 템플릿

`graph.get(v)`의 Edge는 `to,weight`, State는 `vertex,distance`다. `dist`는 MAX_VALUE로 채우고, pq는 distance 오름차순이다.

```java
static long shortestDistance(int start, int target) {
    dist[start] = 0;
    pq.offer(new State(start, 0));
    while (!pq.isEmpty()) {
        State current = pq.poll();
        int vertex = current.vertex;
        if (current.distance != dist[vertex]) continue;
        if (vertex == target) return current.distance;
        for (Edge edge : graph.get(vertex)) {
            long nextDistance = current.distance + edge.weight;
            if (nextDistance >= dist[edge.to]) continue;
            dist[edge.to] = nextDistance;
            pq.offer(new State(edge.to, nextDistance));
        }
    }
    return -1;
}
```

## 왜 이렇게 쓰나

- 음수 간선이 없어서 가장 작은 유효 후보를 꺼낸 뒤 더 먼 곳을 돌아와도 그 거리가 줄지 않는다.
- 힙의 원소는 **넣을 당시 거리**다. 더 짧은 거리를 찾은 뒤 남은 옛 원소는 dist와 비교해 버린다.
- 목적지를 **넣을 때가 아니라 꺼낼 때** 종료한다. 넣은 뒤 더 싼 경로를 찾을 수 있다.

**작게 추적:** `0→1:8, 0→2:2, 2→1:1`: 힙 `[2:2,1:8]` → 2에서 `dist[1]=3` → `1:3` 확정 → 옛 `1:8`은 버림.

> [!info]- 더 자세한 설명
> ### 기존 전체 구현의 개념과 적용 조건
>
> 다익스트라는 아직 확정하지 않은 정점 중 시작점에서 가장 가까운 후보부터 최단거리를 확정하는 알고리즘이다. 간선이 음수가 아니면 더 먼 곳을 거쳐 돌아와 거리가 줄어들 수 없다는 성질을 이용한다.
>
> ## 적용 조건
>
> - 간선마다 비용이 다르고, 시작점에서 목적지까지의 최소 비용이 필요할 때 쓴다.
> - 모든 간선 가중치는 **0 이상**이어야 한다. 음수 간선은 이 템플릿의 대상이 아니다.
> - 간선 비용이 모두 같으면 [[BFS]]로 충분하다.
> - 정점은 `0 ~ n-1`, `edges[i]={출발, 도착, 가중치}`인 **유향 그래프**다.
> - 아래 메서드는 시작점→목적지 거리만 반환한다. 도달할 수 없으면 `-1`이다.
> - 시간 `O(V + E log(E+2))`, 그래프·거리 배열·중복 후보 저장 공간 `O(V+E)`.
> - 거리를 `long`으로 저장한다. 아래 입력 간선의 비용은 `int` 범위의 음이 아닌 값이다.
>
> 간선이 `0→1:8`, `0→2:2`, `2→1:1`, `1→3:4`, `2→3:10`, `3→4:10`이고 시작점 0, 목적지 4라고 하자.
>
> | 꺼낸 `(정점, 거리)` | 갱신 | 남은 핵심 후보 |
> |---|---|---|
> | `(0,0)` | `dist[1]=8`, `dist[2]=2` | `(2,2), (1,8)` |
> | `(2,2)` | `dist[1]=3`, `dist[3]=12` | `(1,3), (1,8), (3,12)` |
> | `(1,3)` | `dist[3]=7` | `(3,7), (1,8), (3,12)` |
> | `(3,7)` | `dist[4]=17` | `(1,8), (3,12), (4,17)` |
> | `(1,8)` | 현재 `dist[1]=3`과 달라 버림 | `(3,12), (4,17)` |
> | `(3,12)` | 현재 `dist[3]=7`과 달라 버림 | `(4,17)` |
> | `(4,17)` | 목적지의 현재 최단 후보, 반환 | 답 17 |
>
> **힙 원소는 그때 발견한 거리의 기록**이다. 1에 거리 8로 넣은 뒤 거리 3을 찾더라도 옛 원소를 직접 삭제하지 않는다. 꺼낼 때 `current.distance != dist[vertex]`로 판별한다.
>
> **왜 꺼낸 뒤 목적지면 끝내는가?** 현재 가장 작은 거리보다 뒤의 후보가 작아질 수 없고, 남은 간선도 음수가 아니다. 따라서 오래된 후보를 건너뛴 후 꺼낸 목적지의 거리는 확정된다. 목적지를 처음 **넣을 때**는 아직 더 짧은 길이 나올 수 있다.
>
> **완화**는 “현재 정점을 거치면 더 짧아지는가?”다. 위 예시의 `2→1`은 `2+1=3 < 8`이라 `dist[1]`을 바꾼다.
>
> ### 주의점
>
> - 무향 간선이면 간선 구성에서 역방향도 추가한다. 한 줄의 입력이 양방향을 뜻하는지 확인한다.
> - 입력 정점이 `1 ~ n`이면 저장 전에 출발/도착과 시작/목적지에서 각각 1을 빼서 통일한다.
> - `start==target`이면 초기 후보에서 바로 0을 반환한다.
> - 거리 후보는 `long`이다. `int`로 합친 뒤 `long`에 넣지 않는다.
> - `visited`를 큐에 넣을 때 표시하면 나중에 찾은 더 짧은 경로를 막을 수 있다. 이 코드는 `dist`와 오래된 후보 검사를 쓴다.
> - 모든 정점의 거리가 필요하면 목적지 조기 반환을 제거하고, 탐색 후 `dist` 배열을 반환하도록 **반환 목표**를 바꾼다.
> - 음수 간선이 있으면 “가장 가까운 후보는 확정”이라는 이유가 깨진다. [[벨만 포드]]를 사용한다.
>
> ## 관련 개념
>
> - [[힙]] — 가장 가까운 후보를 꺼내는 도구
> - [[BFS]] — 가중치가 모두 같을 때의 최단거리

> [!example]- 준비 코드 · 전체 구현
> ### 위 핵심의 준비 코드와 실행 예
>
> 필드·초기화·헬퍼를 포함하며, main의 숫자 사례를 그대로 실행할 수 있다. 새 입력을 풀 때는 배열·큐·방문 상태를 새로 준비한다.
>
> ```java
> import java.util.*;
>
> class GraphKernel8 {
>     static List<List<Edge>> graph;
>     static long[] dist;
>     static PriorityQueue<State> pq;
>     static class Edge {
>         int to, weight;
>         Edge(int to, int weight) { this.to = to; this.weight = weight; }
>     }
>     static class State {
>         int vertex;
>         long distance;
>         State(int vertex, long distance) { this.vertex = vertex; this.distance = distance; }
>     }
>
>     static long shortestDistance(int start, int target) {
>         dist[start] = 0;
>         pq.offer(new State(start, 0));
>         while (!pq.isEmpty()) {
>             State current = pq.poll();
>             int vertex = current.vertex;
>             if (current.distance != dist[vertex]) continue;
>             if (vertex == target) return current.distance;
>             for (Edge edge : graph.get(vertex)) {
>                 long nextDistance = current.distance + edge.weight;
>                 if (nextDistance >= dist[edge.to]) continue;
>                 dist[edge.to] = nextDistance;
>                 pq.offer(new State(edge.to, nextDistance));
>             }
>         }
>         return -1;
>     }
>
>     static void check(boolean success, String message) {
>         if (!success) throw new AssertionError(message);
>     }
>
>     public static void main(String[] args) {
>         graph = new ArrayList<>();
>         for (int i = 0; i < 6; i++) graph.add(new ArrayList<>());
>         for (int[] edge : new int[][] {{0,1,8},{0,2,2},{2,1,1},{1,3,4},{2,3,10},{3,4,10}}) {
>             graph.get(edge[0]).add(new Edge(edge[1], edge[2]));
>         }
>         dist = new long[6];
>         Arrays.fill(dist, Long.MAX_VALUE);
>         pq = new PriorityQueue<>(Comparator.comparingLong(state -> state.distance));
>         check(shortestDistance(0,4) == 17, "improvement and stale candidates");
>         Arrays.fill(dist, Long.MAX_VALUE);
>         pq.clear();
>         check(shortestDistance(0,5) == -1, "unreachable");
>         Arrays.fill(dist, Long.MAX_VALUE);
>         pq.clear();
>         check(shortestDistance(0,0) == 0, "same source and target");
>         System.out.println("PASS 다익스트라");
>     }
> }
> ```
>
> ### 기존 전체 구현
>
>
> ```java
> import java.util.*;
>
> class DijkstraTemplate {
>     static class Edge {
>         int to;
>         int weight;
>
>         Edge(int to, int weight) {
>             this.to = to;
>             this.weight = weight;
>         }
>     }
>
>     static class State {
>         int vertex;
>         long distance;
>
>         State(int vertex, long distance) {
>             this.vertex = vertex;
>             this.distance = distance;
>         }
>     }
>
>     static long shortestDistance(int n, int[][] edges,
>                                  int start, int target) {
>         List<List<Edge>> graph = new ArrayList<>();
>         for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
>         for (int[] edge : edges) {
>             graph.get(edge[0]).add(new Edge(edge[1], edge[2]));
>         }
>
>         long[] dist = new long[n];
>         Arrays.fill(dist, Long.MAX_VALUE);
>         dist[start] = 0;
>
>         PriorityQueue<State> pq = new PriorityQueue<>(
>                 Comparator.comparingLong(state -> state.distance));
>         pq.offer(new State(start, 0));
>
>         while (!pq.isEmpty()) {
>             State current = pq.poll();
>             int vertex = current.vertex;
>
>             if (current.distance != dist[vertex]) continue;
>             if (vertex == target) return current.distance;
>
>             for (Edge edge : graph.get(vertex)) {
>                 long nextDistance = current.distance + edge.weight;
>                 if (nextDistance >= dist[edge.to]) continue;
>
>                 dist[edge.to] = nextDistance;
>                 pq.offer(new State(edge.to, nextDistance));
>             }
>         }
>         return -1;
>     }
> }
> ```

# 비트마스크

> **핵심:** i번째 원소 포함 여부는 `(mask & (1 << i)) != 0`.

## 개념

비트마스크는 원소별 선택·미선택 상태를 정수의 각 비트에 저장하는 방법이다. n개 원소의 부분집합 하나를 n비트 정수 하나로 나타낼 수 있어 집합 상태를 비교하고 전이하기 쉽다.

## 적용 조건

원소 개수가 작고, 모든 부분집합을 확인하거나 선택 상태를 정수 하나로 저장할 때 쓴다. 아래는 n ≤ 20 정도의 작은 배열에서 **합이 target인 부분집합 수**를 센다. 빈 집합도 포함한다. 시간 `O(n·2^n)`, 공간 `O(1)`.

## Java 템플릿

```java
class BitmaskTemplate {
    static long countSubsets(int[] arr, long target) {
        int n = arr.length;
        if (n > 20) throw new IllegalArgumentException("n <= 20");
        long answer = 0;
        for (int mask = 0; mask < (1 << n); mask++) {
            long sum = 0;
            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) != 0) sum += arr[i];
            }
            if (sum == target) answer++;
        }
        return answer;
    }
}
```

> [!info]- 원리와 코드 설명
>
> 원소 `[2,5,7]`은 포함/미포함을 각각 선택하므로 `2³=8`개 상태다. 오른쪽 끝 비트가 인덱스 0이다. mask=5는 이진수 `101`이라 0번과 2번을 고르고 합은 9다.
>
> `1 << 2`는 `100`. `101 & 100 = 100`이므로 2번 원소가 포함되어 있다. 결과는 1일 수도 4일 수도 있으므로 `== 1` 대신 **0이 아닌지** 검사한다.
>
> ### 주의점
>
> - 빈 집합을 제외하려면 mask=1부터 시작한다. target=0일 때 결과가 달라진다.
> - 숫자가 같아도 서로 다른 인덱스를 고르는 경우는 별도 부분집합으로 센다.
> - Java의 int 비트 이동은 큰 n에서 기대한 `2^n`이 되지 않는다. long으로 바꿔도 완전탐색의 지수 증가 자체는 해결되지 않는다.

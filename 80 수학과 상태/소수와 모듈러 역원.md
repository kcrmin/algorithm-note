# 소수와 모듈러 역원

> **핵심:** 소수 판별은 제곱근까지, 여러 수는 체. 나머지의 나눗셈은 역원이 있을 때만 곱셈으로 바꾼다.

## 개념

소수는 1과 자기 자신만 양의 약수로 가지는 2 이상의 정수다. 에라토스테네스의 체는 각 소수의 배수를 지워 많은 수를 한꺼번에 판별한다. 모듈러 역원은 `a×x ≡ 1 (mod m)`을 만족하는 x이며 a와 m이 서로소일 때 존재한다.

## 적용 조건

체는 limit≥0에 대해 시간 `O(limit log log limit)`, 공간 O(limit). 아래 역원은 p가 소수이고 a가 p의 배수가 아닐 때만 사용한다. `2 <= p <= Integer.MAX_VALUE`, a≥0이면 곱셈 중간값이 long 범위 안이다.

## Java 템플릿

```java
import java.util.*;

class PrimeTemplate {
    static boolean[] sieve(int limit) {
        boolean[] prime = new boolean[limit + 1];
        Arrays.fill(prime, true);
        prime[0] = false;
        if (limit >= 1) prime[1] = false;
        for (int p = 2; (long) p * p <= limit; p++) {
            if (!prime[p]) continue;
            for (long multiple = (long) p * p; multiple <= limit; multiple += p) {
                prime[(int) multiple] = false;
            }
        }
        return prime;
    }
    static long inversePrime(long a, long p) {
        a %= p;
        if (a == 0) throw new IllegalArgumentException("inverse does not exist");
        long result = 1, exponent = p - 2;
        while (exponent > 0) {
            if ((exponent & 1) != 0) result = result * a % p;
            a = a * a % p;
            exponent /= 2;
        }
        return result;
    }
}
```

> [!info]- 원리와 코드 설명
>
> limit=10에서 2는 소수라 4,6,8,10을 지운다. 다음 3은 남아 있어 9를 지운다. 남은 2,3,5,7이 소수다. p보다 작은 인수를 가진 p의 배수는 앞에서 이미 지워졌으므로 p²부터 시작해도 된다.
>
> mod 7에서 3의 역원은 5다. `3×5=15≡1`이기 때문이다. 소수 p에서는 `a^(p−1)≡1`이므로 a의 역원은 `a^(p−2)`다. 예를 들어 `6÷3 mod 7`은 일반 나눗셈 구문 대신 `6×5%7=2`로 계산한다.
>
> ### 주의점
>
> - p가 소수인지 이 메서드가 검사하지 않는다. 합성수에 p−2 공식을 쓰면 틀린다.
> - a가 p의 배수면 역원이 없다. 소수 mod라도 0으로 나눌 수 없다.
> - 일반 m에서는 확장 유클리드로 역원을 구하며 gcd(a,m)=1 조건이 필요하다.
> - long 모듈러 곱셈이 항상 안전한 것은 아니다. 위 p 범위를 유지한다.

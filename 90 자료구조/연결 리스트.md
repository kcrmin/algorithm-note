# 연결 리스트

> **핵심:** 노드를 이미 알고 있으면 이웃 링크만 바꿔 삽입·삭제한다. 노드 찾기까지 O(1)인 것은 아니다.

## 개념

연결 리스트는 원소를 연속된 메모리 칸 대신 이전·다음 노드의 연결로 묶는다. 이중 연결 리스트는 양쪽 이웃을 저장하므로, 삭제할 노드의 참조가 있으면 주변 두 연결을 고쳐 O(1)에 삭제할 수 있다.

## 적용 조건

아래는 앞뒤 더미 노드를 둔 이중 연결 리스트다. 삽입·삭제 O(1), 값 검색 O(n), 저장 공간 O(n). remove의 인수는 이 리스트에 속해 있고 아직 삭제되지 않은 실제 노드여야 한다.

## Java 템플릿

```java
class DoublyList {
    static class Node {
        int value;
        Node prev, next;
        Node(int value) { this.value = value; }
    }
    final Node head = new Node(0), tail = new Node(0);
    DoublyList() {
        head.next = tail;
        tail.prev = head;
    }
    Node insertAfter(Node previous, int value) {
        Node node = new Node(value);
        Node following = previous.next;
        node.prev = previous;
        node.next = following;
        previous.next = node;
        following.prev = node;
        return node;
    }
    void remove(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
        node.prev = node.next = null;
    }
}
```

> [!info]- 원리와 코드 설명
>
> `head ↔ 10 ↔ 30 ↔ tail`에서 10 뒤에 20을 넣는다. 먼저 following=30을 기억하고, 20의 prev=10·next=30을 정한다. 이후 10의 next=20, 30의 prev=20으로 바꾸면 `10↔20↔30`이 된다.
>
> 20을 지울 때는 10의 next를 30, 30의 prev를 10으로 연결한다. head/tail은 경계를 대신하므로 첫 원소·마지막 원소도 같은 연결 규칙으로 처리된다.
>
> ### 주의점
>
> - Java LinkedList의 remove(value)는 값을 찾는 데 O(n)이 든다. 위 O(1)은 노드 참조를 알고 있을 때다.
> - ID로 즉시 찾으려면 `Map<Integer, Node>`나 ID 범위가 작은 경우 Node 배열을 함께 쓴다.
> - 삭제한 노드를 다시 삭제하거나 다른 리스트의 노드를 넣으면 링크가 깨진다.

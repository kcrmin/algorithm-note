# 완전탐색과 시뮬레이션

모든 후보를 검사하거나, 명령 순서대로 상태를 바꾸어 답을 구한다.

> **기억:** 완전탐색: 후보 생성 → 조건 검사 → 집계. 시뮬레이션: 명령 읽기 → 다음 상태 계산 → 유효하면 반영.

**전제:** 쌍 탐색 시간 `O(n²)`·공간 `O(1)`. 격자 명령 m개 처리 시간 `O(m)`·공간 `O(1)`.

## 템플릿

위는 서로 다른 인덱스 쌍이다. 아래는 `cur=(0,0)`, `dir=0`에서 시작하며 방향은 오른쪽·아래·왼쪽·위, `1`은 길이다.

```java
static long countPairs(int[] numbers, int target) {
    long count = 0;
    for (int i = 0; i < numbers.length; i++) {
        for (int j = i + 1; j < numbers.length; j++) {
            if ((long) numbers[i] + numbers[j] == target) count++;
        }
    }
    return count;
}

static void simulate(String commands) {
    for (char command : commands.toCharArray()) {
        if (command == 'R') dir = (dir + 1) % 4;
        else if (command == 'L') dir = (dir + 3) % 4;
        else {
            int nx = cur.x + dx[dir];
            int ny = cur.y + dy[dir];
            if (nx < 0 || nx >= W || ny < 0 || ny >= H) continue;
            if (map[ny][nx] == 0) continue;
            cur.x = nx;
            cur.y = ny;
        }
    }
}
```

## 왜 이렇게 쓰나

- `j=i+1`부터 보면 자기 자신을 고르지 않고 `(i,j)`와 `(j,i)`도 중복해서 세지 않는다.
- 위치는 먼저 `nx,ny`로 계산하고 검사한 뒤 바꾼다. 벽에 부딪힌 명령은 현재 위치를 유지한다.
- 방향이 0~3일 때 왼쪽 회전은 `+3`이다. Java의 음수 나머지를 피한다.

**작게 추적:** `[1,2,2,3], 목표 4`의 쌍은 `(0,3),(1,2)`로 2개. 모두 길인 2×2에서 `FRF`: `(0,0,오른쪽) → (1,0) → 아래 → (1,1)`.

> [!info]- 더 자세한 설명
> ### 기존 전체 구현의 개념과 적용 조건
>
> 완전탐색은 가능한 후보를 빠짐없이 만들어 조건을 검사하는 방법이다. 시뮬레이션은 현재 상태를 정의하고, 주어진 사건이나 명령의 순서대로 그 상태를 바꾸는 방법이다.
>
> ## 적용 조건
>
> - **완전탐색**: 입력이 작거나 후보 수를 셀 수 있어서, 모든 경우를 직접 확인할 수 있을 때 쓴다.
> - **시뮬레이션**: 이동, 회전, 교환, 시간 경과 등 문제에 적힌 규칙을 그대로 실행할 때 쓴다.
> - 먼저 후보 수 또는 명령 수를 계산한다. 반복문이 두 개라고 무조건 느린 것도, 코드가 짧다고 빠른 것도 아니다.
> - 아래 완전탐색은 서로 다른 두 **인덱스**의 합이 목표값인 쌍의 개수를 센다. 시간 `O(n²)`, 추가 공간 `O(1)`이다.
> - 아래 시뮬레이션은 길 `1`, 벽 `0`인 격자에서 로봇 명령 `m`개를 처리한다. 시간 `O(m)`, 추가 공간 `O(1)`이다.
> - 시뮬레이션 입력은 비어 있지 않은 직사각형이며, 시작 칸 `(0,0)`은 길이고 명령은 `F`, `R`, `L`만 있다고 가정한다.
>
> ### 1. `j = i + 1`은 중복과 자기 자신을 동시에 제외한다
>
> 배열 `[1,2,2,3]`에서 목표 `4`를 만들 때 확인하는 인덱스 쌍은 다음 여섯 개다.
>
> | `i, j` | 계산 | 누적 `count` |
> | --- | --- | --- |
> | `0, 1` | `1 + 2 = 3` | `0` |
> | `0, 2` | `1 + 2 = 3` | `0` |
> | `0, 3` | `1 + 3 = 4` | `1` |
> | `1, 2` | `2 + 2 = 4` | `2` |
> | `1, 3` | `2 + 3 = 5` | `2` |
> | `2, 3` | `2 + 3 = 5` | `2` |
>
> 항상 `i < j`이므로 `(0,3)`과 `(3,0)`을 중복으로 세지 않고 `(1,1)`처럼 같은 원소를 두 번 쓰지도 않는다.
> 값이 같은 두 `2`도 인덱스가 `1`, `2`로 다르므로 유효한 한 쌍이다.
> 이 문제는 **인덱스 쌍 개수**를 센다. 서로 다른 합의 종류를 세는 문제라면 저장 방식이 달라진다.
>
> 후보 수는 `n(n-1)/2`다. `n = 5,000`이면 `12,497,500`쌍, `n = 100,000`이면 `4,999,950,000`쌍이다.
> 큰 입력에서는 정렬 후 투 포인터나 해시로 줄일 수 있는지 검토한다.
> 합을 계산하기 **전** 하나를 `long`으로 바꿔야 두 `int`의 덧셈에서 넘치는 것을 막는다.
> 쌍 개수도 `int` 범위를 넘을 수 있어 `count`를 `long`으로 둔다.
>
> ### 2. 시뮬레이션은 상태를 먼저 정한다
>
> 이 로봇의 상태는 현재 위치 `(x,y)`와 방향 `dir`이다.
> `x`는 열, `y`는 행이므로 배열은 반드시 `map[y][x]`로 읽는다.
> 오른쪽·아래·왼쪽·위를 `0,1,2,3` 순으로 두면 오른쪽 회전은 `+1`, 왼쪽 회전은 `+3`이다.
> 예를 들어 오른쪽 `0`에서 왼쪽으로 돌면 `(0 + 3) % 4 = 3`, 즉 위쪽이다.
> Java에서 `(0 - 1) % 4`는 `-1`이므로 왼쪽 회전을 그대로 `-1`로 계산하지 않는다.
>
> 다음 지도에서 명령 `FFRFFLFF`를 처리한다.
>
> ```text
>        x=0 1 2
> y=0     1 1 0
> y=1     1 1 1
> ```
>
> | 명령 | 판단 | 실행 후 `(x, y, dir)` |
> | --- | --- | --- |
> | 시작 | 오른쪽을 본다 | `(0,0,0)` |
> | `F` | 오른쪽 `(1,0)`은 길 | `(1,0,0)` |
> | `F` | `(2,0)`은 벽 → 그대로 | `(1,0,0)` |
> | `R` | 아래를 보도록 회전 | `(1,0,1)` |
> | `F` | 아래 `(1,1)`은 길 | `(1,1,1)` |
> | `F` | `(1,2)`는 범위 밖 → 그대로 | `(1,1,1)` |
> | `L` | 오른쪽을 보도록 회전 | `(1,1,0)` |
> | `F` | 오른쪽 `(2,1)`은 길 | `(2,1,0)` |
> | `F` | `(3,1)`은 범위 밖 → 그대로 | `(2,1,0)` |
>
> ### 3. 다음 위치를 계산하고, 유효할 때만 현재 위치를 바꾼다
>
> `nx`, `ny`는 이동 **후보**다. 범위와 벽을 확인하기 전에는 `cur.x`, `cur.y`를 바꾸지 않는다.
> 먼저 현재 위치를 옮기고 실패하면 되돌리는 방식보다, 성공할 때만 갱신하는 편이 상태를 추적하기 쉽다.
> 범위 검사보다 먼저 `map[ny][nx]`를 읽으면 지도 밖 후보에서 배열 인덱스 예외가 난다.
> 원래 지도는 읽기만 하며, 움직인 결과는 `cur`와 `dir`에 기록한다.
>
> ### 주의점
>
> - **완전탐색의 중복 기준**: 순서 있는 쌍인지, 순서 없는 쌍인지, 같은 인덱스 재사용이 가능한지부터 구분한다.
> - **시뮬레이션의 실행 순서**: 회전 후 이동인지 이동 후 회전인지 문제의 규칙 그대로 구현한다.
> - **시간 제한 판단**: 최악의 입력 크기로 반복 횟수를 센다. 시간 제한과 연산 종류에 따라 실제 허용량은 달라진다.
> - **좌표**: `map[ny][nx]`, `nx < W`, `ny < H`를 한 묶음으로 기억한다. 정사각형 예제만 보면 행·열 실수를 놓치기 쉽다.
> - **경계 사례**: 원소가 `0`개·`1`개인 쌍 세기는 `0`, 빈 명령 문자열은 시작 상태 `{0,0,0}`이다.
> - **재호출**: 새 지도마다 `map`, `H`, `W`를 덮어쓰고 위치·방향을 시작 상태로 만든다.
>
> **관련 개념:** [[Java 기본 도구]] · [[백트래킹]] · [[BFS]]

> [!example]- 준비 코드 · 전체 구현
> ### 위 핵심의 준비 코드와 실행 예
>
> 필드·초기화·헬퍼를 포함하며, main의 숫자 사례를 그대로 실행할 수 있다. 새 입력을 풀 때는 배열·큐·방문 상태를 새로 준비한다.
>
> ```java
> import java.util.*;
>
> class GraphKernel3 {
>     static int H, W, dir;
>     static int[][] map;
>     static Point cur;
>     static final int[] dx = {1, 0, -1, 0};
>     static final int[] dy = {0, 1, 0, -1};
>     static class Point {
>         int x, y;
>         Point(int x, int y) { this.x = x; this.y = y; }
>     }
>
>     static long countPairs(int[] numbers, int target) {
>         long count = 0;
>         for (int i = 0; i < numbers.length; i++) {
>             for (int j = i + 1; j < numbers.length; j++) {
>                 if ((long) numbers[i] + numbers[j] == target) count++;
>             }
>         }
>         return count;
>     }
>
>     static void simulate(String commands) {
>         for (char command : commands.toCharArray()) {
>             if (command == 'R') dir = (dir + 1) % 4;
>             else if (command == 'L') dir = (dir + 3) % 4;
>             else {
>                 int nx = cur.x + dx[dir];
>                 int ny = cur.y + dy[dir];
>                 if (nx < 0 || nx >= W || ny < 0 || ny >= H) continue;
>                 if (map[ny][nx] == 0) continue;
>                 cur.x = nx;
>                 cur.y = ny;
>             }
>         }
>     }
>
>     static void check(boolean success, String message) {
>         if (!success) throw new AssertionError(message);
>     }
>
>     public static void main(String[] args) {
>         check(countPairs(new int[] {1,2,2,3}, 4) == 2, "distinct index pairs");
>         check(countPairs(new int[] {Integer.MAX_VALUE, 1}, Integer.MIN_VALUE) == 0, "addition is long");
>         map = new int[][] {{1,1},{1,1}};
>         H = W = 2;
>         cur = new Point(0,0);
>         dir = 0;
>         simulate("FRF");
>         check(cur.x == 1 && cur.y == 1 && dir == 1, "movement and right turn");
>         map = new int[][] {{1,0},{1,1}};
>         cur = new Point(0,0);
>         dir = 0;
>         simulate("FFLFF");
>         check(cur.x == 0 && cur.y == 0 && dir == 3, "wall and boundary stay");
>         System.out.println("PASS 완전탐색과 시뮬레이션");
>     }
> }
> ```

> ### 기존 전체 구현
>
>
> ### 완전탐색: 두 수의 합이 목표인 인덱스 쌍 세기
>
> `solution(new int[] {1, 2, 2, 3}, 4)`의 결과는 `2`다.
> 두 `Solution` 코드는 서로 다른 문제용이다. 각자 하나씩 복사해 사용한다.
>
> ```java
> public class Solution {
>     public long solution(int[] numbers, int target) {
>         long count = 0;
>
>         for (int i = 0; i < numbers.length; i++) {
>             for (int j = i + 1; j < numbers.length; j++) {
>                 if ((long) numbers[i] + numbers[j] == target) {
>                     count++;
>                 }
>             }
>         }
>
>         return count;
>     }
> }
> ```
>
> ### 시뮬레이션: 전진과 회전 명령 처리
>
> 로봇은 `(0,0)`에서 오른쪽을 보고 시작한다. `F`는 한 칸 전진, `R`은 오른쪽 회전, `L`은 왼쪽 회전이다.
> 벽이나 지도 밖으로 전진하라는 명령은 무시한다. 반환값은 `{x, y, dir}`다.
>
> ```java
> public class Solution {
>     static int H, W;
>     static int[][] map;
>     // dir: 0 오른쪽, 1 아래, 2 왼쪽, 3 위
>     static final int[] dx = {1, 0, -1, 0};
>     static final int[] dy = {0, 1, 0, -1};
>
>     static class Point {
>         int x;
>         int y;
>
>         Point(int x, int y) {
>             this.x = x;
>             this.y = y;
>         }
>     }
>
>     public int[] solution(int[][] matrix, String commands) {
>         map = matrix;
>         H = map.length;
>         W = map[0].length;
>         Point cur = new Point(0, 0);
>         int dir = 0;
>
>         for (int step = 0; step < commands.length(); step++) {
>             char command = commands.charAt(step);
>             if (command == 'R') {
>                 dir = (dir + 1) % 4;
>             } else if (command == 'L') {
>                 dir = (dir + 3) % 4;
>             } else { // F
>                 int nx = cur.x + dx[dir];
>                 int ny = cur.y + dy[dir];
>
>                 if (nx < 0 || nx >= W || ny < 0 || ny >= H) {
>                     continue;
>                 }
>                 if (map[ny][nx] == 0) {
>                     continue;
>                 }
>
>                 cur.x = nx;
>                 cur.y = ny;
>             }
>         }
>
>         return new int[] {cur.x, cur.y, dir};
>     }
> }
> ```

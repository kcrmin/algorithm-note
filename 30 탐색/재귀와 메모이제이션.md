# 재귀와 메모이제이션

같은 하위 문제의 답을 저장하여 재귀 호출의 중복 계산을 없앤다.

> **기억:** 종료 조건 → 계산했으면 캐시 반환 → 작은 문제 호출 → 답 저장 → 반환.

**전제:** n≥0인 피보나치, MOD=1,000,000,007. 시간·공간 `O(n)`, 재귀 깊이 `O(n)`.

## 템플릿

`memo`와 `computed`는 길이 n+1로 새로 만들고 `solve(n)`을 호출한다. 큰 n은 호출 스택 때문에 반복 DP로 바꾼다.

```java
long solve(int n) {
    if (n <= 1) return n;
    if (computed[n]) return memo[n];
    memo[n] = (solve(n - 1) + solve(n - 2)) % MOD;
    computed[n] = true;
    return memo[n];
}
```

## 왜 이렇게 쓰나

- 종료 조건이 먼저 있어야 재귀가 바닥에서 돌아온다. 호출 직후의 계산은 **하위 호출이 반환한 뒤** 이어진다.
- 답 0도 유효할 수 있으므로 `memo[n]==0`을 미계산 표시로 쓰지 않고 `computed`로 구분한다.
- 캐시 키에는 답에 영향을 주는 상태가 모두 필요하다. 위치가 같아도 남은 연료가 다르면 다른 문제다.

**작게 추적:** `solve(4) → solve(3) → solve(2)=1` 저장 → `memo[3]=2` → 두 번째 `solve(2)`는 저장한 1 반환 → `memo[4]=3`.

> [!info]- 더 자세한 설명
> ### 기존 전체 구현의 개념과 적용 조건
>
> 재귀 함수는 자기 자신을 호출해 더 작은 문제로 내려가고, 종료 조건의 반환값을 받아 원래 문제의 답을 만든다. 메모이제이션은 **같은 인수가 같은 하위 문제를 뜻할 때** 이미 계산한 답을 캐시에 저장하는 탑다운 DP다.
>
> ## 적용 조건
>
> 아래는 n번째 피보나치 수를 1,000,000,007로 나눈 값이다. n≥0. 상태 n+1개를 한 번씩 계산하므로 시간·공간 `O(n)`, 재귀 깊이 `O(n)`이다. 큰 n은 재귀 깊이 때문에 반복 DP가 적합하다.
>
> `solve(4)`는 `solve(3)+solve(2)`를 기다린다. `solve(3)`은 다시 `solve(2)+solve(1)`을 기다린다. `solve(2)`가 1을 계산해 돌아오면 memo[2]=1로 저장한다. 그 위에서 memo[3]=2가 되고, 마지막에 다시 필요한 solve(2)는 계산 없이 1을 반환해 memo[4]=3이 된다.
>
> 호출을 한 직후 다음 줄이 실행되는 것이 아니다. **하위 호출이 return해야 멈췄던 계산이 이어진다.** 종료 조건이 없거나 인수가 줄지 않으면 호출이 끝나지 않는다.
>
> 캐시 상태에 필요한 정보를 빠뜨리면 다른 문제를 같은 문제로 오인한다. 예를 들어 같은 위치라도 남은 연료가 다르면 결과가 달라지는 문제는 위치만 키로 쓸 수 없다.
>
> ### 주의점
>
> - 정답이 0인 상태도 있어서 memo[n]==0을 미계산 표시로 쓰면 안 된다. computed로 구분한다.
> - 상태 사이에 순환이 있으면 이 단순 재귀 캐시로 종료가 보장되지 않는다.
> - 캐시를 공유할 때 입력이 달라지면 기존 답은 더 이상 유효하지 않을 수 있다.
>
> **관련 개념:** [[DP]] · [[백트래킹]] · [[DFS와 그래프]]

> [!example]- 준비 코드 · 전체 구현
> ### 위 핵심의 준비 코드와 실행 예
>
> 필드·초기화·헬퍼를 포함하며, main의 숫자 사례를 그대로 실행할 수 있다. 새 입력을 풀 때는 배열·큐·방문 상태를 새로 준비한다.
>
> ```java
> import java.util.*;
>
> class GraphKernel4 {
>     static final int MOD = 1_000_000_007;
>     long[] memo;
>     boolean[] computed;
>
>     long solve(int n) {
>         if (n <= 1) return n;
>         if (computed[n]) return memo[n];
>         memo[n] = (solve(n - 1) + solve(n - 2)) % MOD;
>         computed[n] = true;
>         return memo[n];
>     }
>
>     static void check(boolean success, String message) {
>         if (!success) throw new AssertionError(message);
>     }
>
>     public static void main(String[] args) {
>         GraphKernel4 instance = new GraphKernel4();
>         instance.memo = new long[101];
>         instance.computed = new boolean[101];
>         check(instance.solve(4) == 3, "numeric trace");
>         check(instance.computed[2] && instance.computed[3], "memoized subproblems");
>         check(instance.solve(0) == 0 && instance.solve(1) == 1, "base cases");
>         check(instance.solve(100) == 687995182L, "modular recurrence");
>         System.out.println("PASS 재귀와 메모이제이션");
>     }
> }
> ```
>

# 이분 탐색

불가능 F에서 가능 T로 한 번 바뀌는 후보 중 **첫 true**를 찾는다.

> **기억:** 0부터 max → 가운데 검사 → 참은 남겨 왼쪽 → 거짓은 버려 오른쪽.

**전제:** FFFTTT로 한 번 바뀌고, 범위 안에 true가 존재해야 한다. 시간은 `검사 비용 × O(log 범위)`.

`max`는 답을 포함하는 상한이고, `valid(long x)`는 같은 클래스의 판정 메서드다. 답을 반환하는 메서드 안에 쓴다.

## 템플릿

```java
long left = 0, right = max;
while (left < right) {
    long mid = left + (right - left) / 2;
    if (valid(mid)) {
        right = mid;
    } else {
        left = mid + 1;
    }
}
return left;
```

## 왜 이렇게 쓰나

- `right = mid`: 참인 mid 자체가 첫 성공일 수 있으므로 남긴다.
- `left = mid + 1`: 거짓인 mid와 그 왼쪽은 전부 실패하므로 버린다.
- `left < right`: 후보 하나가 남으면 그 값이 답이다. 참이 하나도 없으면 이 전제가 깨진다.

1. `max = 5`, 조건 `x >= 3`: `[0,5]`의 `mid = 2`는 F → `[3,5]`.
2. `mid = 4`는 T → `[3,4]`.
3. `mid = 3`은 T → `[3,3]`, 답 `3`.

**관련 개념:** [[이분 탐색 - 마지막 true]] · [[배열 이분 탐색]] · [[투 포인터]] · [[누적합]]

> [!info]- 더 자세한 설명
> ### 범위와 판정을 정하는 순서
>
> 후보 값을 늘릴 때 가능 여부가 FFFTTT인지 먼저 쓴다. 문제에 “최소”가 있다는 이유만으로 고르면 안 된다. TFTF처럼 여러 번 바뀌면 이 방식으로 절반을 버릴 수 없다.
>
> `left`는 첫 후보 값으로 바꿀 수 있다. 닫힌 구간 `[left, right]` 안에 true가 적어도 하나 있어야 하며, FFFTTT에서는 오른쪽 끝이 true인지 확인하면 된다. 아래 전체 메서드는 true가 없을 때 `-1`을 반환한다.
>
> `(left + right) / 2` 대신 차이를 이용해 mid를 만든다. 여기서는 `0 <= left <= right < Long.MAX_VALUE`여서 계산이 안전하다. 음수부터 양수까지 long 전체 범위를 가로지르는 탐색에 그대로 적용하지 않는다.
>
> ### 입국심사에 연결
>
> `times = [7,10]`, `n = 6`이면 시간 x의 처리 인원은 `x / 7 + x / 10`이다. 27분에는 5명, 28분에는 6명이다. 시간이 늘어도 처리 인원은 줄지 않으므로 FFFTTT이며 답은 28이다.
>
> `right = (long) minTime * n`이면 가장 빠른 심사관 한 명만 일해도 전원을 처리하므로 상한이 true다. `(long)`은 곱하기 **전**에 붙인다.
>
> 배열에서 첫 `arr[i] >= target`을 찾는 lower bound는 [[배열 이분 탐색]]을 본다. 그 템플릿은 정답 위치가 없으면 n을 돌려주도록 끝 다음 위치까지 다룬다.

> [!example]- 준비 코드 · 전체 구현
> 아래 메서드는 클래스 안에 둔다. `LongPredicate`는 전체 구현을 재사용하기 위한 인자다. 첫 화면에서는 문제의 `valid(mid)`를 직접 작성하면 된다.
>
> ```java
> static long firstTrue(long left, long right,
>                       java.util.function.LongPredicate valid) {
>     if (!valid.test(right)) {
>         return -1;
>     }
>
>     while (left < right) {
>         long mid = left + (right - left) / 2;
>
>         if (valid.test(mid)) {
>             right = mid;
>         } else {
>             left = mid + 1;
>         }
>     }
>
>     return left;
> }
> ```
>
> 입국심사 예시의 전제는 `n >= 1`, 비어 있지 않은 `times`, 모든 심사 시간이 양수다.
>
> ```java
> static long immigration(int n, int[] times) {
>     int minTime = times[0];
>     for (int duration : times) {
>         minTime = Math.min(minTime, duration);
>     }
>     long right = (long) minTime * n;
>
>     return firstTrue(0, right, time -> {
>         long processed = 0;
>         for (int duration : times) {
>             long capacity = time / duration;
>             if (capacity >= n - processed) {
>                 return true;
>             }
>             processed += capacity;
>         }
>         return false;
>     });
> }
> ```

# 2차원 누적합

> **핵심:** `prefix[y + 1][x + 1]`은 원본의 `(0, 0)`부터 `(x, y)`까지의 직사각형 합이다. 인덱스는 항상 `matrix[y][x]` 순서다.

## 개념

2차원 누적합은 원점에서 각 칸까지의 직사각형 합을 미리 저장한다. 원하는 직사각형을 큰 직사각형에서 위쪽·왼쪽 영역을 빼고 중복으로 빠진 모서리를 더해 `O(1)`에 구한다. [[누적합]]의 구간 차이를 행과 열 두 방향으로 확장한 형태다.

## 적용 조건

| 연산 | 시간 |
|---|---|
| 전처리 | `O(HW)` |
| 직사각형 합 | `O(1)` |
| 공간 | `O(HW)` |

- 모든 행의 길이가 같은 격자이며, 전처리 후 원소 갱신이 없다. 값은 음수여도 된다.
- **`x`는 열, `y`는 행**이다. 좌표를 받는 `sum(x1, y1, x2, y2)`의 양 끝은 포함한다.
- 가로 또는 세로가 빈 범위(`x1 > x2` 또는 `y1 > y2`)의 합은 `0`이다.

## Java 템플릿

```java
final class PrefixSum2D {
    private final int height, width;
    private final long[][] prefix;

    PrefixSum2D(long[][] matrix) {
        height = matrix.length;
        width = height == 0 ? 0 : matrix[0].length;
        prefix = new long[height + 1][width + 1];

        for (int y = 0; y < height; y++) {
            if (matrix[y].length != width) throw new IllegalArgumentException();
            for (int x = 0; x < width; x++) {
                prefix[y + 1][x + 1] = matrix[y][x]
                        + prefix[y][x + 1]
                        + prefix[y + 1][x]
                        - prefix[y][x];
            }
        }
    }

    long sum(int x1, int y1, int x2, int y2) {
        if (x1 > x2 || y1 > y2) return 0;
        if (x1 < 0 || y1 < 0 || x2 >= width || y2 >= height) {
            throw new IndexOutOfBoundsException();
        }
        return prefix[y2 + 1][x2 + 1]
             - prefix[y1][x2 + 1]
             - prefix[y2 + 1][x1]
             + prefix[y1][x1];
    }
}
```

> [!info]- 원리와 코드 설명
>
> 원본이 아래와 같다고 하자. 오른쪽 아래 값 `4`의 좌표는 `(x, y) = (1, 1)`이다.
>
> ```text
> matrix[y][x]       prefix[y][x]
>       x=0  x=1         x=0  x=1  x=2
> y=0    1    2     y=0   0    0    0
> y=1    3    4     y=1   0    1    3
>                  y=2   0    4   10
> ```
>
> **누적합 생성:** `prefix[2][2] = 4 + prefix[1][2] + prefix[2][1] - prefix[1][1] = 4 + 3 + 4 - 1 = 10`이다. 위쪽 합 `3`과 왼쪽 합 `4`에 왼쪽 위의 값 `1`이 둘 다 들어 있으므로 한 번 뺀다. 0행·0열을 모두 `0`으로 비워 두면 첫 행과 첫 열도 같은 식으로 처리된다.
>
> **직사각형 조회:** `sum(1, 1, 1, 1)`은 오른쪽 아래 한 칸의 합이다.
>
> | 항 | 포함 영역 | 값 |
> |---|---|---:|
> | `+ prefix[y2 + 1][x2 + 1]` | 오른쪽 아래 끝점까지 전체 | +10 |
> | `- prefix[y1][x2 + 1]` | 원하는 영역보다 위 | -3 |
> | `- prefix[y2 + 1][x1]` | 원하는 영역보다 왼쪽 | -4 |
> | `+ prefix[y1][x1]` | 위·왼쪽에서 두 번 빠진 모서리 | +1 |
> | 결과 | `10 - 3 - 4 + 1` | **4** |
>
> 왼쪽 경계 `x1`과 위쪽 경계 `y1`에는 `+1`이 없다. 해당 위치 **직전까지의 원본 영역**을 빼기 때문이다. 반대로 `x2`, `y2`는 끝 칸까지 포함하므로 누적합 인덱스에 각각 `+1`을 붙인다. 같은 공식으로 오른쪽 열은 `sum(1, 0, 1, 1) = 10 - 0 - 4 + 0 = 6`이다.
>
> ### 주의점
>
> - 메서드 인자는 `(x, y)` 순서지만 배열 접근은 `[y][x]` 순서다. 행·열 개수가 다른 격자에서 특히 쉽게 드러나는 실수다.
> - 문제 좌표가 1부터 시작하면 호출 전에 좌표 4개에서 각각 1을 뺀다.
> - 원본 값을 바꿔도 누적합은 자동 갱신되지 않는다. 중간 합까지 모두 `long` 범위 안이어야 한다.
> - 행이나 열이 0개인 입력은 생성할 수 있다. 이 경우 비어 있지 않은 직사각형 조회는 유효하지 않다.

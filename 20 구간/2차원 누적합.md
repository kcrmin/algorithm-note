# 2차원 누적합

원점부터 쌓은 직사각형 합에서 위와 왼쪽을 빼고, 두 번 빠진 모서리를 한 번 더한다.

> **기억:** 위 + 왼쪽 − 겹침으로 쌓기 → 전체 − 위 − 왼쪽 + 모서리로 조회.

**전제:** 같은 너비의 격자, 전처리 뒤 갱신 없음, 유효한 양 끝 포함 좌표, 음수 허용. 전처리·공간 `O(HW)`, 조회 `O(1)`.

`matrix[y][x]`, 높이 H·너비 W, 좌표 `(x1,y1)`부터 `(x2,y2)`를 받는 long 메서드 안이다. 여러 조회에서는 prefix를 한 번만 만든다.

## 템플릿

```java
long[][] prefix = new long[H + 1][W + 1];
for (int y = 0; y < H; y++) {
    for (int x = 0; x < W; x++) {
        prefix[y + 1][x + 1] = matrix[y][x]
                + prefix[y][x + 1] + prefix[y + 1][x]
                - prefix[y][x];
    }
}
return prefix[y2 + 1][x2 + 1]
        - prefix[y1][x2 + 1] - prefix[y2 + 1][x1]
        + prefix[y1][x1];
```

## 왜 이렇게 쓰나

- 배열은 `[행 y][열 x]`다. 0행·0열을 비워 첫 행과 첫 열도 같은 식으로 쌓는다.
- 쌓을 때 위와 왼쪽의 겹침을 한 번 뺀다. 조회할 때 두 번 빠진 모서리는 한 번 되돌린다.
- 끝 좌표 `x2,y2`는 포함하므로 +1, 시작 좌표 `x1,y1`은 직전 영역을 빼므로 그대로다.

1. `[[1,2],[3,4]]`에서 누적합 오른쪽 아래는 `4 + 3 + 4 - 1 = 10`.
2. 오른쪽 아래 한 칸 `(1,1)~(1,1)`은 `10 - 3 - 4 + 1 = 4`.
3. 오른쪽 열 `(1,0)~(1,1)`은 `10 - 0 - 4 + 0 = 6`.

**관련 개념:** [[누적합]] · [[Fenwick 트리]] · [[세그먼트 트리]]

> [!info]- 더 자세한 설명
> ### 0행과 0열
>
> ```text
> matrix[y][x]        prefix[y][x]
>     1  2              0  0  0
>     3  4              0  1  3
>                       0  4 10
> ```
>
> `prefix[y + 1][x + 1]`은 원본 (0,0)부터 (x,y)까지의 직사각형 합이다. 한 칸씩 큰 배열이므로 맨 위나 맨 왼쪽을 빼는 계산에서도 인덱스가 음수가 되지 않는다.
>
> 메서드 인자는 `(x,y)` 순서지만 배열은 `[y][x]`다. 행·열 수가 다른 격자로 확인하면 뒤바꾼 실수를 잡기 쉽다. 입력 좌표가 1부터 시작하면 네 좌표에서 각각 1을 뺀다.
>
> 전체 구현은 가로나 세로가 빈 범위의 합을 0으로 돌려주고, 유효 범위를 벗어난 조회는 예외로 처리한다. 행이나 열이 0개인 격자는 만들 수 있지만 비어 있지 않은 사각형을 조회할 수는 없다.
>
> 원본을 바꿔도 누적합은 갱신되지 않는다. 중간 계산까지 long 범위 안이어야 한다.

> [!example]- 준비 코드 · 전체 구현
> 아래 클래스는 생성 시 한 번 쌓고 sum을 여러 번 호출하는 형태다.
>
> ```java
> final class PrefixSum2D {
>     private final int height, width;
>     private final long[][] prefix;
>
>     PrefixSum2D(long[][] matrix) {
>         height = matrix.length;
>         width = height == 0 ? 0 : matrix[0].length;
>         prefix = new long[height + 1][width + 1];
>
>         for (int y = 0; y < height; y++) {
>             if (matrix[y].length != width) throw new IllegalArgumentException();
>             for (int x = 0; x < width; x++) {
>                 prefix[y + 1][x + 1] = matrix[y][x]
>                         + prefix[y][x + 1]
>                         + prefix[y + 1][x]
>                         - prefix[y][x];
>             }
>         }
>     }
>
>     long sum(int x1, int y1, int x2, int y2) {
>         if (x1 > x2 || y1 > y2) return 0;
>         if (x1 < 0 || y1 < 0 || x2 >= width || y2 >= height) {
>             throw new IndexOutOfBoundsException();
>         }
>         return prefix[y2 + 1][x2 + 1]
>              - prefix[y1][x2 + 1]
>              - prefix[y2 + 1][x1]
>              + prefix[y1][x1];
>     }
> }
> ```

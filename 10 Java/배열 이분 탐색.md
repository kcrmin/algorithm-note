# 배열 이분 탐색

정렬 배열에서 target 이상인 첫 위치인 **lower bound**를 찾는다.

> **기억:** 0부터 n → 가운데 비교 → 이상이면 남겨 왼쪽 → 작으면 버려 오른쪽.

**전제:** `arr` 오름차순. 시간 `O(log n)`, 공간 `O(1)`; 없으면 n, 빈 배열이면 0.

`arr`, `target`을 받는 int 메서드 안에 쓴다. right는 검사하지 않는 끝 다음 위치다.

## 템플릿

```java
int left = 0, right = arr.length;
while (left < right) {
    int mid = left + (right - left) / 2;
    if (arr[mid] >= target) {
        right = mid;
    } else {
        left = mid + 1;
    }
}
return left;
```

## 왜 이렇게 쓰나

- `>= target`이면 mid도 첫 위치일 수 있어 남기고, 작으면 mid까지 전부 버린다.
- right를 n으로 두면 답이 없는 경우도 n으로 모인다. 반복 중 mid는 n보다 작다.
- **upper bound**는 조건 한 줄만 `> target`으로 바꾼다. 같은 값의 개수는 `upper - lower`다.

1. `[1,3,3,5]`, target 3: `[0,4)`에서 mid 2의 값 3 → right 2.
2. mid 1의 값 3 → right 1, mid 0의 값 1 → left 1. lower는 1.
3. upper는 같은 3들을 지나 첫 5의 위치 3. 개수는 `3 - 1 = 2`.

**관련 개념:** [[이분 탐색]] · [[이분 탐색 - 마지막 true]] · [[LIS]] · [[정렬]]

> [!info]- 더 자세한 설명
> ### 끝 다음 위치 n
>
> `[1,3,3,5]`에서 target 6이면 모든 값이 작아 left가 4에 도달한다. `arr[4]`는 읽지 않는다. 결과가 arr.length이면 실제 원소가 아니므로 접근 전에 확인한다.
>
> lower bound 결과 p가 target의 실제 위치인지 확인하려면 `p < arr.length && arr[p] == target`을 검사한다. target 2의 lower bound는 1이지만 arr[1]은 3이므로 2가 존재한다는 뜻은 아니다.
>
> ### 경계 이름
>
> | 찾는 위치 | 조건 | `[1,3,3,5]`, target 3 |
> | --- | --- | ---: |
> | lower bound | 첫 `>= target` | 1 |
> | upper bound | 첫 `> target` | 3 |
> | 마지막 `<= target` | upper bound − 1 | 2 |
>
> `Arrays.binarySearch`는 중복된 값의 첫 위치를 보장하지 않는다. `upper bound`를 [[이분 탐색 - 마지막 true]]와 혼용하지 않는다.

> [!example]- 준비 코드 · 전체 구현
> 두 메서드를 함께 둔 전체 구현이다.
>
> ```java
> class ArrayBounds {
>     static int lowerBound(int[] arr, int target) {
>         int left = 0, right = arr.length;
>         while (left < right) {
>             int mid = left + (right - left) / 2;
>             if (arr[mid] >= target) right = mid;
>             else left = mid + 1;
>         }
>         return left;
>     }
>     static int upperBound(int[] arr, int target) {
>         int left = 0, right = arr.length;
>         while (left < right) {
>             int mid = left + (right - left) / 2;
>             if (arr[mid] > target) right = mid;
>             else left = mid + 1;
>         }
>         return left;
>     }
> }
> ```

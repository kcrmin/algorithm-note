# 스택과 큐

스택은 나중에 넣은 것부터, 큐는 먼저 넣은 것부터 꺼낸다.

> **기억:** 스택 `push → pop` · 큐 `offer → poll` · 확인만 하면 `peek`.

**전제:** 둘 다 ArrayDeque. 끝의 삽입·제거는 분할상환 O(1).

## 템플릿

```java
Deque<Integer> stack = new ArrayDeque<>();
stack.push(10);
stack.push(20);
int last = stack.pop();   // 20

Queue<Integer> queue = new ArrayDeque<>();
queue.offer(10);
queue.offer(20);
int first = queue.poll(); // 10
```

## 왜 이렇게 쓰나

- 스택은 가장 최근 미처리 항목을 꺼낸다. 괄호 짝·되돌리기에 맞는다.
- 큐는 들어온 순서를 지킨다. 대기열·BFS에 맞는다.
- pop/poll 전에 비었는지 확인한다. 빈 스택의 pop은 예외이고, 빈 큐의 poll은 null이다.

`10 → 20 → 30`을 넣으면 스택은 `30,20,10`, 큐는 `10,20,30` 순서로 나온다.

> [!info]- 더 자세한 설명
>
> `"(())"`에서 스택 크기는 `0 → 1 → 2 → 1 → 0`이다. 닫는 괄호는 가장 최근에 열린 괄호를 하나 소모한다.
>
> `"())"`에서는 두 번째 `')'`를 만났을 때 스택이 비어 있다. 짝지을 여는 괄호가 없으므로 **pop 전에** 실패를 반환한다. 반대로 `"(("`은 중간에 실패하지 않아도 끝에 여는 괄호가 남으므로 마지막 `isEmpty()`가 필요하다.
>
> 큐에 `10,20,30`을 `offer`하면 `poll`은 `10,20,30` 순서다. 스택에 같은 값을 `push`하면 `pop`은 `30,20,10` 순서다. 함수 이름을 섞으면 처리 순서가 바뀐다.
>
> ### 단조 스택을 만났다면
>
> “현재 값보다 작은/큰 이전 원소를 한꺼번에 처리한다”면 스택에 **인덱스**를 넣는다. 예를 들어 가격 `[3,2,4]`에서 2가 들어오면 인덱스 0의 가격 3은 하락이 확정된다. 아직 확정되지 않은 인덱스만 남기는 방식이다. 현재 값이 들어올 때 조건을 깬 이전 인덱스를 확정하는 방식이다. 별도 템플릿은 [[단조 스택과 덱]]에 있다.
>
> ### 주의점
>
> - `peek`는 확인만, `poll/pop`은 제거한다. 빈 스택의 `pop`은 예외다.
> - `ArrayDeque`에는 null을 넣지 않는다. 빈 큐의 `poll`은 null이므로 빈 상태에서 int로 받으면 오류가 난다.
> - 괄호가 `()` 한 종류뿐이면 스택 대신 정수 개수로도 구현할 수 있다. 위 코드는 스택의 처리 순서를 배우는 기준이다.
> - 최솟값부터 꺼내려면 일반 큐가 아니라 [[힙]]이다.

> [!example]- 준비 코드 · 전체 구현
>
> 필요한 import와 초기화까지 포함한 전체 코드다. 각 코드 블록은 별도 예시다.
>
> ```java
> import java.util.*;
>
> class DequeTemplate {
>     static boolean validParentheses(String s) {
>         Deque<Character> stack = new ArrayDeque<>();
>         for (int i = 0; i < s.length(); i++) {
>             char ch = s.charAt(i);
>             if (ch == '(') {
>                 stack.push(ch);
>             } else if (ch == ')') {
>                 if (stack.isEmpty()) return false;
>                 stack.pop();
>             } else {
>                 return false; // 이 메서드는 괄호 두 종류만 받는다.
>             }
>         }
>         return stack.isEmpty();
>     }
>
>     static int[] processInOrder(int[] arr) {
>         Queue<Integer> queue = new ArrayDeque<>();
>         for (int value : arr) queue.offer(value);
>         int[] result = new int[arr.length];
>         int index = 0;
>         while (!queue.isEmpty()) {
>             result[index++] = queue.poll();
>         }
>         return result;
>     }
> }
> ```

# 해시

HashMap은 이름별 값을, HashSet은 값의 존재만 빠르게 관리한다.

> **기억:** 개수는 `getOrDefault + 1` · 중복 없는 보관은 `Set.add`.

**전제:** names는 문자열 배열. 해시 조회·삽입은 평균 O(1), 전체 평균 O(n).

## 템플릿

```java
Map<String, Integer> count = new HashMap<>();
for (String name : names) {
    count.put(name, count.getOrDefault(name, 0) + 1);
}

Set<String> unique = new HashSet<>();
for (String name : names) {
    unique.add(name);
}
```

## 왜 이렇게 쓰나

- 처음 나온 이름은 값이 없으므로 기본 0에서 1을 더한다.
- Map의 값은 등장 횟수, Set은 있었는지만 남긴다.
- `set.add(x)`가 false면 이미 들어 있던 값이다. 정렬 순서는 보장하지 않는다.

`[민,준,민]` → count는 `{민:2, 준:1}`, unique는 `{민,준}`. 빈도를 줄여 0이 되었을 때 종류 수도 줄여야 한다면 키를 remove한다.

> [!info]- 더 자세한 설명
>
> `names = ["민", "준", "민"]`을 세어 보자.
>
> | 읽은 이름 | 기존 개수 | 저장할 개수 | Map 상태 |
> |---|---:|---:|---|
> | 민 | 없음 → 기본 0 | 1 | 민:1 |
> | 준 | 없음 → 기본 0 | 1 | 민:1, 준:1 |
> | 민 | 1 | 2 | 민:2, 준:1 |
>
> 처음 나온 이름에 `count.get(name) + 1`을 쓰면 `null`을 숫자로 바꾸는 과정에서 오류가 난다. 없는 경우 0을 주는 `getOrDefault`가 필요한 이유다.
>
> Set은 값별로 한 자리만 가진다. `[4,7,4]`에서 `add(4) → true`, `add(7) → true`, 다시 `add(4) → false`다. **새로 넣지 못했다 = 이미 있었다**이므로 중복을 찾는다.
>
> 빈도를 하나 줄일 때는 기존 값에서 1을 빼서 `put`한다. 값이 0이 되어도 키는 남는다. “종류 수”를 `map.size()`로 셀 문제라면 0이 된 키를 `remove`해야 한다.
>
> ### 주의점
>
> - 값 범위가 0~25처럼 작고 고정이면 `int[26]` 카운트가 더 단순하다. ID가 크고 듬성듬성하면 Map이 편하다.
> - 키 존재는 `containsKey`, 값 가져오기는 `get`. 없는 값의 처리 방식을 먼저 정한다.
> - 순회 중 같은 Map의 구조를 직접 바꾸면 오류가 날 수 있다. 키 집합을 돌며 삭제하는 코드를 습관적으로 쓰지 않는다.
> - 합·누적값을 키로 쓰면 `Map<Long, ...>`. long의 0은 `0L`이다.

> [!example]- 준비 코드 · 전체 구현
>
> 필요한 import와 초기화까지 포함한 전체 코드다. 각 코드 블록은 별도 예시다.
>
> ```java
> import java.util.*;
>
> class HashTemplate {
>     static Map<String, Integer> countNames(String[] names) {
>         Map<String, Integer> count = new HashMap<>();
>         for (String name : names) {
>             count.put(name, count.getOrDefault(name, 0) + 1);
>         }
>         return count;
>     }
>
>     static boolean hasDuplicate(int[] arr) {
>         Set<Integer> seen = new HashSet<>();
>         for (int value : arr) {
>             if (!seen.add(value)) return true;
>         }
>         return false;
>     }
> }
> ```

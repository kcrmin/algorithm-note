# 단조 스택과 덱

단조 스택은 아직 답을 못 찾은 원소만 크기 순서대로 남긴다. 아래는 각 원소 오른쪽의 첫 큰 값이 있는 **인덱스**다.

> **기억:** 현재 값이 더 크면 이전 원소의 답 확정 → 현재 인덱스 넣기.

**전제:** arr은 int 배열. 없으면 -1. O(n): 각 인덱스는 한 번 넣고 한 번 뺀다.

## 템플릿

```java
int[] answer = new int[arr.length];
Arrays.fill(answer, -1);
Deque<Integer> stack = new ArrayDeque<>();
for (int i = 0; i < arr.length; i++) {
    while (!stack.isEmpty() && arr[stack.peek()] < arr[i]) {
        answer[stack.pop()] = i;
    }
    stack.push(i);
}
```

## 왜 이렇게 쓰나

- 이전 값보다 큰 현재 값이 왔다면, 그 이전 값의 “오른쪽 첫 큰 값이 있는 위치”가 지금 확정된다.
- 하나뿐 아니라 여러 개의 답이 확정될 수 있어 if가 아니라 while이다.
- 같은 값은 더 큰 값이 아니므로 `<`를 쓴다. 인덱스를 저장해야 답을 제자리에 기록한다.

`[2,1,3]`: 2,1은 대기 → 인덱스 2의 값 3이 오면 두 답 모두 위치 2 → 결과 `[2,2,-1]`. 값이 필요하면 그 인덱스로 arr를 읽는다.

> [!example]- 준비 코드 · 전체 구현
>
> 필요한 import와 초기화까지 포함한 전체 코드다. 각 코드 블록은 별도 예시다.
>
> ```java
> import java.util.ArrayDeque;
> import java.util.Arrays;
> import java.util.Deque;
>
> final class Monotonic {
>     static int[] nextGreaterIndex(int[] a) {
>         int[] next = new int[a.length];
>         Arrays.fill(next, -1);
>         Deque<Integer> stack = new ArrayDeque<>();
>
>         for (int i = 0; i < a.length; i++) {
>             while (!stack.isEmpty() && a[stack.peek()] < a[i]) {
>                 next[stack.pop()] = i;
>             }
>             stack.push(i);
>         }
>         return next;
>     }
>
>     static int[] slidingMax(int[] a, int k) {
>         if (k <= 0 || k > a.length) throw new IllegalArgumentException();
>         int[] result = new int[a.length - k + 1];
>         Deque<Integer> deque = new ArrayDeque<>();
>
>         for (int i = 0; i < a.length; i++) {
>             while (!deque.isEmpty() && deque.peekFirst() <= i - k) {
>                 deque.pollFirst();
>             }
>             while (!deque.isEmpty() && a[deque.peekLast()] <= a[i]) {
>                 deque.pollLast();
>             }
>             deque.addLast(i);
>             if (i >= k - 1) result[i - k + 1] = a[deque.peekFirst()];
>         }
>         return result;
>     }
> }
> ```

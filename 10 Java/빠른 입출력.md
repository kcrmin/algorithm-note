# 빠른 입출력

입력은 줄 단위로 묶어 읽고, 출력도 모아 보내면 반복 호출 비용을 줄일 수 있다.

> **기억:** 줄 읽기 → 토큰으로 나누기 → 숫자로 변환 · 출력은 모아서 한 번.

**전제:** 아래는 한 줄에 정수 두 개가 있는 경우. java.io.*, java.util.* 사용.

## 템플릿

```java
BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
StringTokenizer st = new StringTokenizer(br.readLine());
int a = Integer.parseInt(st.nextToken());
int b = Integer.parseInt(st.nextToken());

StringBuilder out = new StringBuilder();
out.append((long) a + b).append('\n');
System.out.print(out);
```

## 왜 이렇게 쓰나

- `readLine()`은 한 줄, `nextToken()`은 그 줄의 다음 공백 구분 값이다.
- 다음 줄을 읽으면 StringTokenizer도 새 줄로 다시 만든다.
- 숫자가 여러 줄에 흩어져 있거나 입력이 매우 크면 아래 FastInput 전체 구현을 쓸 수 있다.

입력 `12 7` → 토큰 `"12"`, `"7"` → 정수 12, 7 → 출력 `19`. 이 뼈대는 두 숫자가 같은 줄에 있다는 전제다.

> [!info]- 더 자세한 설명
>
> `-12 7`에서 '-'를 읽으면 음수 표시만 저장한다. 숫자 '1'에서 value=1, 다음 '2'에서 `1×10+2=12`다. 공백을 만나 숫자 읽기를 끝내고 -12를 반환한다. 다음 호출은 남은 '7'을 읽는다.
>
> read의 index가 length에 닿았다는 것은 현재 버퍼를 다 썼다는 뜻이다. 다음 덩어리를 읽고 index=0으로 돌아간다. 파일 끝에서 -1을 반환하므로 공백만 남은 입력에서도 무한 반복하지 않는다.
>
> value를 long으로 쌓는 이유는 int 최솟값 -2,147,483,648의 **양의 크기**가 int에 들어가지 않기 때문이다. 입력 자체가 int 범위라는 전제 아래 마지막 부호 처리 뒤 변환한다.
>
> ### 주의점
>
> - 형식이 잘못되거나 int 범위를 넘는 입력을 검증하는 범용 파서는 아니다.
> - 출력 전체가 매우 크면 StringBuilder도 메모리를 쓴다. 일정 크기마다 BufferedWriter로 내보낼 수 있다.

> [!example]- 준비 코드 · 전체 구현
>
> 필요한 import와 초기화까지 포함한 전체 코드다. 각 코드 블록은 별도 예시다.
>
> ```java
> import java.io.*;
>
> class FastInput {
>     private final InputStream in;
>     private final byte[] buffer = new byte[1 << 16];
>     private int length = 0, index = 0;
>
>     FastInput(InputStream in) { this.in = in; }
>     private int read() throws IOException {
>         if (index >= length) {
>             length = in.read(buffer);
>             index = 0;
>             if (length <= 0) return -1;
>         }
>         return buffer[index++] & 255;
>     }
>     int nextInt() throws IOException {
>         int ch;
>         do {
>             ch = read();
>             if (ch == -1) throw new EOFException();
>         } while (ch <= ' ');
>         boolean negative = ch == '-';
>         if (negative) ch = read();
>         long value = 0;
>         while (ch >= '0' && ch <= '9') {
>             value = value * 10 + ch - '0';
>             ch = read();
>         }
>         return (int) (negative ? -value : value);
>     }
> }
> ```

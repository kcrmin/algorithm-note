# 단조 덱 - 구간 최댓값

단조 덱은 현재 구간에서 최댓값이 될 수 있는 후보 인덱스만 남긴다.

> **기억:** 앞: 기간 지난 것 제거 → 뒤: 더 작은 것 제거 → 현재 넣기 → 앞이 최댓값.

**전제:** 1 ≤ k ≤ arr.length. 길이 k의 모든 구간 최댓값, O(n).

## 템플릿

```java
Deque<Integer> deque = new ArrayDeque<>();
int[] answer = new int[arr.length - k + 1];
for (int i = 0; i < arr.length; i++) {
    while (!deque.isEmpty() && deque.peekFirst() <= i - k) {
        deque.pollFirst();
    }
    while (!deque.isEmpty() && arr[deque.peekLast()] <= arr[i]) {
        deque.pollLast();
    }
    deque.offerLast(i);
    if (i >= k - 1) answer[i - k + 1] = arr[deque.peekFirst()];
}
```

## 왜 이렇게 쓰나

- i에서 구간은 `[i-k+1,i]`. 따라서 i-k 이하 인덱스는 기간이 끝났다.
- 이전 값이 현재 값 이하라면 값도 작고 더 먼저 만료된다. 앞으로 최댓값일 수 없어 뒤에서 버린다.
- 살아 있는 후보는 큰 순서라 앞의 값이 현재 최댓값이다.

`[2,1,3]`, k=2 → `[2,1]`의 답 2 → 3이 오면 1과 2가 후보에서 빠짐 → `[1,3]`의 답 3.

>     }

# 정렬

정렬은 기준을 정해 원소를 줄 세우는 연산이다.

> **기억:** 첫 기준 비교 → 다르면 반환 → 같으면 동점 기준 비교.

**전제:** 행마다 [시작, 끝]인 int[][] meetings. 끝 오름차순, 동점이면 시작 오름차순. O(n log n).

## 템플릿

```java
Arrays.sort(meetings, (a, b) -> {
    int order = Integer.compare(a[1], b[1]);
    if (order != 0) return order;
    return Integer.compare(a[0], b[0]);
});
```

## 왜 이렇게 쓰나

- 비교 결과가 음수면 a가 앞, 양수면 b가 앞이다.
- 첫 기준이 같을 때만 두 번째 기준을 본다.
- `a-b`는 넘쳐서 부호가 뒤집힐 수 있어 `Integer.compare`를 쓴다.

`[3,5], [1,3], [0,3] → [0,3], [1,3], [3,5]`. 끝이 3인 둘이 먼저 오고, 그 안에서는 시작이 0인 것이 앞이다.

> [!info]- 더 자세한 설명
>
> 비교 함수의 결과는 **음수면 a를 앞에, 0이면 같은 우선순위, 양수면 b를 앞에** 놓는다는 뜻이다.
>
> `[시작, 끝] = [[3,5], [1,3], [0,3]]`을 정렬해 보자.
>
> 1. 끝이 3인 두 구간이 끝이 5인 구간보다 앞이다.
> 2. 끝이 같은 `[1,3]`, `[0,3]`은 시작을 비교한다.
> 3. 결과는 `[[0,3], [1,3], [3,5]]`다.
>
> `a[1] - b[1]`도 작은 값에서는 비교처럼 보인다. 하지만 `2_000_000_000 - (-2_000_000_000)`은 int 범위를 넘어서 부호가 뒤집힌다. `Integer.compare`는 그 실수를 피한다. long 값은 `Long.compare`다.
>
> 내림차순은 인자를 바꾼 `Integer.compare(b[1], a[1])`다. 숫자를 빼거나 비교 결과를 임의로 뒤집는 공식을 추가로 외울 필요가 없다.
>
> ### 주의점
>
> - `int[]`에는 Comparator를 직접 붙일 수 없다. 내림차순 출력이면 오름차순 정렬 후 뒤에서 읽으면 된다. 꼭 객체 비교가 필요하면 `Integer[]`를 쓴다.
> - 문자열 사전순은 `a.compareTo(b)`. 숫자 문자열 `"10"`이 `"2"`보다 앞이므로 숫자 크기와 다르다.
> - 정렬은 원본 배열 순서를 바꾼다. 원래 인덱스가 필요하면 함께 저장한다.
> - Comparator는 항상 일관된 순서를 반환해야 한다. 동점에도 무조건 1을 반환하면 안 된다.

> [!example]- 준비 코드 · 전체 구현
>
> 필요한 import와 초기화까지 포함한 전체 코드다. 각 코드 블록은 별도 예시다.
>
> ```java
> import java.util.*;
>
> class SortingTemplate {
>     static void sortNumbers(int[] arr) {
>         Arrays.sort(arr);
>     }
>
>     // 각 원소는 [시작, 끝]. 끝 오름차순, 같으면 시작 오름차순.
>     static void sortIntervals(int[][] intervals) {
>         Arrays.sort(intervals, (a, b) -> {
>             int byEnd = Integer.compare(a[1], b[1]);
>             if (byEnd != 0) return byEnd;
>             return Integer.compare(a[0], b[0]);
>         });
>     }
> }
> ```
